# 🏛️ Cidadão.AI

Agente inteligente baseado em RAG para consulta à Carta de Serviços da Prefeitura Municipal de Pinheiral.

## 🎯 Objetivo

Desenvolver um agente de inteligência artificial capaz de responder perguntas em linguagem natural utilizando como base de conhecimento a Carta de Serviços ao Cidadão da Prefeitura Municipal de Pinheiral.

## 📚 Base de conhecimento

O projeto utiliza:

- Carta de Serviços ao Cidadão em PDF;
- dados estruturados dos serviços em JSON.

## 🚧 Status

Projeto em desenvolvimento para o Challenge Alura Agente.

## 🛠️ Tecnologias previstas

- Python
- LangChain
- Modelo de linguagem
- Embeddings
- ChromaDB
- Streamlit
- Docker
- Oracle Cloud Infrastructure (OCI)
